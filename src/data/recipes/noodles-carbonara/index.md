title: Noodles carbonara
duration: PT10M
tags: []
category: Pasta
difficulty: Facil
heroImage: ./noodles-carbonara.webp
servings: 1
ingredients: 
  - { quantity: "1", ingredient: "Paquet de tonkotsu ramen" }
  - { quantity: "2", ingredient: "Ous" }
  - { quantity: "20g", ingredient: "Parmesà" }
  - { ingredient: "Pebre" }
steps:
  - Posar aigua a bullir en una olla petita.
  - Separar 2 rovells d'ou i mesclar amb el parmesà ratllat i el pebre en un bol.
  - Obrir el paquet de tokotsu ramen, abocar els sobres a la mescla de formatge i rovells i remenar.
  - Un cop l'aigua estigui bullint abocar els fideus i deixar el temps que indiqui el paquet.
  - Passat el temps de cocciò de la pasta reservar una mica d'aigua i abocar els fideus al bol amb la mescla.
  - Barrejar els fideus amb la mescla i afegir aigua de cocció per modificar la textura al gust.
