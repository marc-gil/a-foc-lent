servings: 3
ingredients: 
  - { quantity: "1", ingredient: "Broquil" }
  - { quantity: "3", ingredient: "Botifarra" }
  - { quantity: "200g", ingredient: "Nyoquis" }
  - { quantity: "2", ingredient: "Yogur grec" }
  - { quantity: "1", ingredient: "Llimona" }
  - { ingredient: "Formatge ratllat", comments: "al gust" }
  - { ingredient: "Oli" }
  - { ingredient: "Pebre" }
  - { ingredient: "Sal" }
steps:
  - Preescalfar el forn a màxima potència.
  - Tallar el broquil en arbrets petits del tamany d'una mossegada.
  - En una bandeja de vidre abocar el broquil i el nyoquis, afegir oli abundant (es el que fara que el menjar es cuini de manera més uniforme), mesclar amb les mans fins que tot estigui impregnat d'oli i repartir uniformement per la bandeja.
  - Descamisar les botifarres, pessigar amb els dits troçets del tamany d'una mossegada i col·locar per sobre de la bandeja.
  - Salpebrar la bandeja i introduir al forn durant uns 25-30 min (el temps depen del forn, anar revisant i girant si fos necessari).
  - En un bol afegir els 2 yogurs, toc de sal i pebre, un xorret de suc de llimona, una mica d'aigua i remenar. Ha de quedar una consistencia més líquida que la del propi yogur pero sense ser molt aigualida).
  - Un cop retirada la bandeja del forn expremer la llimona per tota la bandeja, ratllar el parmesa, servir les racions i afegir la salsa al gust.
