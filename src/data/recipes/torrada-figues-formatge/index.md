  - { quantity: "25g", ingredient: "Pernil salat", comments: "Substituible per qualsevol ingredient salat com pasta d'anxoves, miso, olivada..." }
  - { ingredient: "Mantega" }
steps:
  - Tallar la torrada de pa per la meitat, tallar les figues a rodanxes, el formatge en lamines i muntar l'entrepa.
  - Escalar una paella, afegir una mica de mantega i torrar el pa per ambdues cares, tornant a afegir mantega en el moment de girar la torrada.
